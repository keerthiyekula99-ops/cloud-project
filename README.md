Automated CI/CD and Cloud Deployment

Overview

This project demonstrates an automated Continuous Integration (CI) pipeline using GitHub Actions and Docker. A Flask web application is containerized with Docker, stored in GitHub, and automatically validated and built whenever code is pushed to the main branch.

Features

* Flask-based web application
* Docker containerization
* Git version control
* GitHub repository hosting
* Automated GitHub Actions workflow
* Automatic dependency installation
* Automatic Python syntax validation
* Automatic Docker image build on every push

Project Workflow

Developer → Git Push → GitHub Actions → Install Dependencies → Syntax Check → Docker Build → Success

Technologies Used

* Python 3.11
* Flask
* Docker
* Git
* GitHub
* GitHub Actions
